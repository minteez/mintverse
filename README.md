# Mintverse — Projects by Minteez

**Mintverse** is a personal digital showcase documenting my journey into Generative AI, vibe coding, AI-assisted web development, and creative experimentation.

The journey began in **July 2026**, when I discovered how Generative AI could help turn ideas and prompts into functional websites, games, and interactive digital experiences. What started as learning and experimentation gradually became a growing collection of projects built using tools such as **Gemini, Claude, Lovable, Canva, Bolt, HTML, CSS, JavaScript, TypeScript, and GitHub Pages**.

Rather than being a traditional portfolio or resume, Mintverse is a **project archive**—a place where every website I've created can be discovered and accessed from a single homepage.

## What You'll Find

Mintverse brings together projects created for different reasons:

* **Course capstones** developed as part of my AI Superstar course
* **Educational projects** created for learning and school activities
* **Personal experiments** built while exploring new ideas
* **Creative projects** involving history, poetry, storytelling, and design
* **Games and interactive experiences** developed for fun
* **AI-assisted web projects** created by experimenting with different development tools

Each project is presented with its name, description, relevant category, creation platform where applicable, and a direct link to the live website.

## The Beginning

My website and game development journey started in **July 2026**, after I began learning about Generative AI and discovered that AI could be used not only for answering questions, but also for helping create real digital products.

I started experimenting with prompts, code generation, website design, AI-powered development platforms, and eventually different approaches to building complete projects.

Some projects were created during my learning process. Others came from ideas I had myself, ideas suggested by relatives, school requirements, or simply things I wanted to build because they sounded interesting.

That experimentation eventually became the foundation of Mintverse.
